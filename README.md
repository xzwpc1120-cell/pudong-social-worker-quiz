# 浦东社工备考训练室

面向上海浦东新区社区工作者招聘考试的互动练习网站。

## 功能

- 2025 年上半年、2025 年下半年、2026 年上半年相关客观练习题
- 每卷随机抽取 10、15、20 或 30 题
- 答错即时显示正确答案与解析，答对不打断训练
- 交卷后展示成绩、完整答卷及逐题解析
- 错题保存在浏览器本地；错题训练答对后自动移除
- 首页提供通知、公告、倡议书、请示、报告及材料作文范文
- 支持电脑和手机浏览

> 本题库依据公开考情和相关知识点整理，不是官方原卷或官方标准答案。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 构建

```bash
npm run build
```
